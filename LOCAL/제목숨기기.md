# 문서 상단에 나타나는 타이틀(제목)을 숨기기

Quarto에서 문서 상단에 나타나는 타이틀(제목)을 숨기는 가장 간단한 방법은 YAML 헤더에서 타이틀을 삭제하는 것이지만, 문서의 메타데이터(브라우저 탭 이름 등)는 유지하고 싶다면 format 옵션을 사용하여 시각적으로 숨길 수 있습니다.

## 방법 1: HTML 포맷에서 타이틀 숨기기
YAML 헤더에 title-block-style: none을 추가하여 타이틀 블록이 렌더링되지 않도록 합니다.

```yaml
title: "나의 문서 제목"
format:
  html:
    title-block-style: none
```

## 방법 2: CSS를 사용하여 숨기기 (더 확실한 방법)
CSS를 통해 타이틀 클래스(quarto-title)를 보이지 않게 설정합니다.

```yaml
title: "나의 문서 제목"
format:
  html:
    toc: true
    include-in-header:
      text: |
        <style>
        .quarto-title {
          display: none;
        }
        </style>
```

## 방법 3: 메타데이터는 유지하고 제목만 없애기 (pagetitle 사용)
title 대신 pagetitle을 사용하면 브라우저 탭에는 제목이 표시되지만, 문서 본문에는 제목이 나타나지 않습니다. 

```yaml
pagetitle: "브라우저 탭 제목"
# title은 작성하지 않음
```
